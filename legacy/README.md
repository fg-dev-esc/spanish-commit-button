# Legacy

Esta carpeta esta reservada para codigo inactivo retirado de Spanish Commit Button.

## Politica

- El codigo activo no puede importar desde esta carpeta.
- Su contenido no forma parte del VSIX.
- No se corrigen ni amplian funcionalidades archivadas.
- No se guardan API keys, diffs reales, repositorios, archivos `.env` ni artefactos VSIX.
- Cada elemento movido debe documentar su uso anterior y el motivo del archivo.
